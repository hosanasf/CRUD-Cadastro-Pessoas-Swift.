# CRUD-Cadastro-Pessoas-Swift.
CRUD - Cadastro de Pessoas em Swift

Descrição

Projeto acadêmico desenvolvido em Swift para praticar operações CRUD (Create, Read, Update e Delete) por meio de um sistema de cadastro de pessoas.

Funcionalidades

- Incluir dados de uma pessoa.
- Alterar dados de uma pessoa.
- Apagar dados de uma pessoa.
- Consultar os dados de uma pessoa pelo nome.
- Exibir os dados de todas as pessoas cadastradas.
- Impedir o cadastro de nomes repetidos.

Dados cadastrados

Cada pessoa possui os seguintes campos:

- Nome
- E-mail
- Telefone
- Idade

Tecnologias e conceitos utilizados

- Linguagem Swift
- Dicionários
- Funções
- Estruturas condicionais
- "switch" e "case"
- "readLine()"
- Operações CRUD

Armazenamento

Os dados são armazenados em um dicionário durante a execução do programa. Os registros não são mantidos após o encerramento.

Execução

O programa pode ser executado em um compilador Swift on-line, como o Programiz.

Objetivo

Praticar os conceitos de programação e desenvolver um sistema simples de cadastro de pessoas
